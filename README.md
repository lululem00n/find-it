## About the Game :)

Find It is a 2D platformer made for the Haven event, featuring the Haven hedgehog mascot as the main character throughout the game, I drew the mascot pixel by pixel using LibreSprite, which was a bit challenging for me.

The game takes place in an autumn-themed environment to match the Haven theme, I used a pre-made tileset and existing background assets because creating backgrounds isn't really my strongest skill, but I chose resources that fit the style I wanted for the game.

## Objective

The goal is to guide the hedgehog through the level, overcome different obstacles and collect all five autumn leaves scattered around the map, you have to explore the platforms and find every leaf to win!

Watch your steps, jump across platforms, and try to collect every leaf!

## Controls

A: Move left

D: Move right

W or Space: Jump

## Development

I created Find It to learn and practice the basics of game development with Godot, while making the game, I worked on player movement, jumping, animations, collisions and level design.

I drew the main character's pixel art myself and used existing assets for the autumn environment, this project is simple, but it gave me the chance to create something of my own and practice skills that are useful for me as a Haven co-organizer.
